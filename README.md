# 真空トレーナー

『スーパーストリートファイターII X』のリュウで、中足キャンセル真空波動拳を自力で出せるようになるための、非自動化トレーニングツールです。

ブラウザ上で入力を記録し、実戦的な仕込み入力 `↓↘→ → ↓＋中K → ↘→＋P`（数値表記では `2362＋中K36＋P`）の順序と所要フレームを判定します。ゲームへコマンドを送るマクロではありません。

画面左側のレバー入力タイムラインには、方向記号、テンキー表記、9方向の略図、その方向を保持したフレーム数が表示されます。ニュートラルも記録するため、斜め抜けやレバーを戻す時間を確認できます。

中Kとパンチも方向入力の間へ記録されます。中Kは先行入力 `2362` の成立、パンチは中K後の `36` と目標フレーム内の押下を検査し、成功・方向不足・遅い入力を色分けします。

## 使い方

1. GitHub Pagesで公開されたページをスマートフォンまたはPCで開く
2. `↓↘→`を先に入力し、続けて`↓＋中K`、中足が出たら素早く`↘→＋P`と入力する
3. 判定結果と入力履歴を見て、速度と抜けた方向を修正する

### キーボード

- 方向: 矢印キー
- 中K: `J`
- 弱P／中P／強P: `U`／`I`／`O`
- 向き変更: `F`
- リセット: `Esc`

### USBアケコン

ブラウザのGamepad APIを使用します。「アケコン接続」を押してから、レバーまたはボタンを一度入力してください。機種ごとにボタン番号が異なるため、設定画面で中Kとパンチの番号を変更できます。

## 判定について

- 60 fps換算で下中Kからパンチまでの入力間隔を表示します。
- 初期設定の中K後の目標時間は16フレームです。実機・移植・基板設定に合わせて調整してください。
- 方向入力は右向き／左向きの両方に対応します。
- 成功判定は練習用の目安であり、ゲーム内部の受付処理を完全に再現するものではありません。

## ゲームセンターでの利用

筐体や店舗設備には接続・改造せず、スマートフォンのテンポ提示と入力イメージ練習に使ってください。実機入力を取得する場合は、店舗管理者の許可を得たうえで、自分のアケコンと絶縁したセンサーを使用してください。

## Picoについて

最初の段階ではラズパイは不要です。PCとUSBアケコンがあれば入力解析できます。将来、物理スイッチの入力取得器を作る場合は Raspberry Pi Pico 2、フォトカプラ、抵抗、配線材を使い、ゲーム側へ入力を注入しない「読み取り専用」にします。

## ローカル起動

静的ファイルだけで動作します。

```sh
python -m http.server 8080
```

`http://localhost:8080` を開いてください。
